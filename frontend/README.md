# @medipick/ui

MediPick Shared Frontend Design System and Component Library.

## Features:
- **Tokens:** Canonical healthcare color palette (Mid Teal #1D6F72, Soft Lime #C7E36B, Plum #6B4473), typography, and 4px spacing scale.
- **Components:** DataTable, Pagination, StatusBadge, StatCard, Modal, CustomSelect, CustomDatePicker, ValidationModal.
- **Navigation:** Collapsible SidebarLayout for web dashboards, UserProfileBadge, NotificationBanner.
- **Utils:** Currency formatting (formatLKR), Sri Lanka date/time helpers, phone normalization, PDF/Excel export.
- **Auth:** Universal JWT token storage and AuthGuard wrapper.

## Installation
```bash
npm install ../medipick-core/frontend
# or
npm install ../medipick-common/frontend
```
